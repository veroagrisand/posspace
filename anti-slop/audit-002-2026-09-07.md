## Permintaan pengguna (paket & RBAC)

- **RBAC limit kasir per paket** (shop.ts): starter = 1 kasir, pro = 3 kasir,
  tumbuh = tanpa batas. Ditegakkan di undang anggota & ubah peran
  (`KASIR_LIMIT_REACHED`), dengan toast alasan di UI pengaturan.
- **Ekspor laporan** (Excel/PDF/CSV) digate ke paket Pro+ (`PLAN_FEATURE_UNAVAILABLE`).
- **Tahunan -20%**: migrasi `0021_plans_rbac.sql` menetapkan `annual_price =
  round(monthly * 0.8)` persis untuk starter/pro/tumbuh; diskon ditampilkan
  dari harga server.
- **Teks paket**: fitur paket diselaraskan dengan gateway aktif (Mayar, bukan
  iPaymu/Duitku) dan default landing (Ekspor laporan Excel/PDF).
- **QRIS di kasir**: diverifikasi kasir TIDAK memakai QRIS dinamis; pembayaran
  QRIS dicatat sebagai QRIS statis milik toko tanpa gateway (komentar di
  payment.ts sudah menyatakan ini).
